# Intelligent Loan Approval & Credit Risk Prediction

A machine learning-based web application that predicts loan approval and assesses credit risk using a Random Forest classification model.

## Project Overview

The system analyzes important financial, credit, employment, and loan-related information to predict whether a loan application is likely to be approved or rejected.

The application provides:

* Loan approval prediction
* Approval and rejection probability
* Credit risk classification
* Model performance metrics
* Model explainability
* Interactive Streamlit dashboard
* FastAPI-based prediction backend

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest
* FastAPI
* Streamlit
* Matplotlib
* Joblib

## Machine Learning

The project uses a **Random Forest Classifier** for loan approval prediction.

### Preprocessing

The machine learning pipeline includes:

1. Missing value handling
2. Feature scaling using StandardScaler
3. Categorical feature encoding using OneHotEncoder
4. Feature selection using Mutual Information
5. Random Forest classification

## How to Run

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd loan-risk-prediction
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Start the FastAPI backend

```bash
uvicorn backend.main:app --reload
```

The backend will run at:

`http://127.0.0.1:8000`

### 6. Start the Streamlit frontend

Open another terminal and run:

```bash
streamlit run frontend/app.py
```

The Streamlit application will open in your browser.

## Main Features

### Loan Prediction

Users can enter important personal, financial, credit, and loan information to receive a prediction.

### Risk Analysis

Displays the applicant's predicted credit risk based on the model output.

### Model Performance

Displays important evaluation metrics such as accuracy, precision, recall, F1-score, and ROC-AUC.

### Explainability

Provides insights into the features that contribute to the model's predictions.
